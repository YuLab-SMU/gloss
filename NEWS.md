# gloss 0.0.0.9000

## Page capture (2026-11-11, ADR-0006)

- `gloss()` lets the figure draw itself on its svglite device and captures that page: an object is printed (`show()` for S4), a grob drawn with `grid.draw()`, a function called, a recorded plot replayed. Engines no longer build the grob gloss draws. An object with its own `print()` method is captured as what that method draws (ggbreak's cut axis, ggExtra's marginal plots); the refusal by class is gone.
- gloss compares the captured page with the page drawn, primitive for primitive and with clip regions. Equal: captured. A figure that draws differently each time (random label placement, for example) is captured with a warning and the verdict `not_deterministic`. A capture that changed the figure stops with an error. The verdict, the kind of page, how it was drawn and the page count are in `meta$page` and printed with the figure.
- A function or a recorded plot that draws with grid is captured by the grid engine; it used to stop with "EXPR must be a length 1 vector". A grob whose name is a vector (treemap) is captured. A page with nothing on it and a page mixing base graphics and grid are refused with the reason. An input that draws several pages is captured as its last page, with a warning.
- Engine plugins: `grob(state)` is no longer part of the contract. New optional fields: `page` (`"grid"` or `"base"`), which chooses among engines declaring the same class, and `draw(state)`, for an engine that must keep what drawing returns (ComplexHeatmap's drawn list); its page must be the page the input draws, and `gl_test_plugin()` checks it on `example()`.
- A base-graphics page is captured as base graphics draws it on svglite, no longer as gridGraphics redraws it: its display list is replayed one entry at a time and each entry's primitives become one leaf, named by its call (`plotXY`, `text`, `axis`, `rect`, ...), with expected counts for points, lines, text, rectangles and segments. On 26 hand-built base pages the captured page equals the code's own page in 26 (through gridGraphics: 14; `pairs()`, `persp()`, `image()`, dendrograms, `rect(border = 0)` and `par(bg =)` differed, plotmath stopped with an error). Panels are the figures of the page with their plot region and `usr` scales. A plot recorded elsewhere is replayed with svglite's text metrics, noted in `meta$page$note`.
- A ggplot's built tables are the data drawn even when the build draws random numbers (`position_jitter()` without a seed): the engine draws the build it keeps, as ggplot2's `print()` does. They used to come from another build, which put none of 32 jittered rows on their point.
- Tables and panels that gloss cannot show describe the page drawn are withheld, with the reason in `fig$status$withheld` and in the printed figure: the built data and panels of a ggplot printed by another class's print method (ggbreak), the built data of a patchwork plot whose two builds differ, and panels whose number does not match the page. Raw tables are kept.

## Fixes found by the bench development set (2026-11-10)

- A ggplot without layers is captured, alone or as a wrapped patchwork element (`wrap_elements()`, `wrap_ggplot_grob()`); it used to fail with "subscript out of bounds".
- A ggplot extension whose own `ggplot_build()` returns something other than a built ggplot (gganimate's animations) is refused with the reason, instead of failing while drawing.
- A figure whose `print()` method is not a standard draw path (ggbreak's cut axis, ggExtra's marginal plots) is refused with the reason, instead of being captured as a different figure with no error. Correction (2026-11-10, later): only ggbreak's figure was captured as a different one. ggExtra's `print()` draws the same grob gloss captured; it is refused because the check is by class, which is stricter than needed.
- A clipping grob (`grid::clipGrob()`) keeps clipping the leaves drawn after it. It used to be wrapped in a graphics group like any leaf, which ended its clip with the group: the following leaves were captured unclipped, with no error. It is no longer listed as a leaf (it draws nothing).
- Bench capture runs (development only) now record a fidelity verdict per figure, the primitives that differ, known exceptions with their reason, and which leaves carry a count mismatch.

## M0: the substrate (2026-11-09)

- `gloss()` captures a ggplot, patchwork, ComplexHeatmap, base (through gridGraphics) or grid figure into a read-only substrate. Each leaf grob is drawn once inside its own graphics group with a zero-output probe, so every drawn element is attributed by the device to its leaf, viewport and panel. A leaf whose expected and drawn element counts differ is marked `count_mismatch` and is not bindable. Masked figures are refused.
- Geometry queries: `gl_elements()`, `gl_leaf()`, `gl_panels()`, `gl_hit()`, `gl_near()`, `gl_overlap()`, `gl_to_pixel()`, `gl_to_data()`.
- Tables (raw, built and engine-specific) with inferred row keys (`gl_infer_key()`, five rules in order, each recorded with its basis), `gl_tables()`, `gl_table()`, `gl_key_values()`, and `gl_key()` to change a key.
- Leaves with 10,000 or more elements are kept as a raster drawn from the same grob plus a binary geometry index.
- Context is sniffed at capture time (code, data, engine, environment, document, git) and listed by `gl_context()`; items that cannot be found carry a reason.
- `gl_write()` writes a bundle directory or a single HTML or SVG file with the bundle embedded; `gl_read()` restores either, as well as bundles without data, bundles naming a missing plugin, and plain SVG (geometry only). `embed =` chooses which data travel.
- Plugins: `gl_register()`, `gl_unregister()`, `gl_plugin()`, `gl_plugins()`, `gl_plugin_kinds()`, `gl_test_plugin()`, `gl_schema_check()`, `gl_schema_validate()`. The built-in engines, context sniffers and projections register through `gl_register()`.
