# gloss 0.0.0.9000

## Binding on tree figures (2026-11-11, tree binding plan)

- A page with an embedded image larger than the XML parser's limit for one node (about 10 MB of base64) is captured; gloss stopped with the parser's error ("Huge input lookup"), neither capturing nor refusing it. An SVG read from outside with such a node is refused with the parser's reason; only pages gloss drew itself are parsed without the limit.
- Text is checked in its own frame: a label moved off its row by justification (`hjust = -.1`, `vjust = -.5`, any value) or rotated by an angle is verified, along its baseline to 0.5 pt. A label's box (`geom_label()`) is checked by the centre of its box. Rotated text used to be left unbound and justified labels failed, though rightly paired.
- Rows are put on the page through the coord's own transform, so layers under `coord_polar()` bind: points, text, and segments (drawn as paths along the coord, checked by their ends). A curve (`geom_curve()`) is checked by its ends too. Under a coord that is not linear, rectangles and lines through a group, which the coord bends, are unbound with that reason.
- Text drawn as glyph outlines (`showtext`, which `emojifont` turns on) is reported as outlines, with the counts of paths, labels and characters, and never compared as shapes.
- Points are counted and checked symbol by symbol. A points grob is expected to draw what R's engine draws for each `pch` (pch 8 is four lines, pch 7 a square and two lines; a character is one text, `"."` a small rect; codes 26-31 and `NA` nothing), less what its settings remove: a point whose position or size is not finite, the lines of a symbol under a blank line type or an `NA` line width, the circles of a symbol of size zero. Settings a leaf takes from its parents count. A ggplot points leaf in several shapes (`scale_shape_manual(values = 1:8)`) used to be a count mismatch; each row is now paired with its symbol's parts in drawing order, each part checked by its box, so a dense leaf binds too. A character symbol drawn as a glyph outline (`showtext`) is checked as text is, by its outline's box. A point at `NA` in a hand-built grid grob is no longer expected to draw.
- Base graphics points (`plot()`, `points()`) are counted and checked symbol by symbol, as grid's are. Base draws a symbol's lines whatever `lty` says, and nothing for a point whose `cex` is 0, negative or `NA`. A base page with `pch = 3` used to be a count mismatch.
- ggplot rows are compared as the geom draws them:
  - rows that ggplot2 drops before drawing (`NA` in a required aesthetic, such as an `NA` label) are not paired, so a layer of node labels with `NA` at the tips binds;
  - a geom that moves its rows when drawing by its `nudge_x`/`nudge_y` parameters (ggtree's aligned dotted lines) is checked at the moved place;
  - a geom's `hjust`/`vjust` parameter is taken as the rows' justification.
- Images bind. One drawn per row is checked by its box (by its corners where the rows have bounds); when its justification is not the centre, the row must lie inside the box along that axis. One raster drawn for a layer (`geom_raster()`, tidyterra's RGB rasters) is checked against the bounds of its cells. Images used to be unbound with "no comparison".
- What gloss cannot check is said, not failed:
  - a leaf the layer's grob makes only when drawn (ggrepel's labels and connectors, geomtextpath's text) is unbound with that reason when the layer's rows do not pass for it;
  - a leaf that repeats a passing sibling moved by one offset (shadowtext's halo) is unbound as a copy, with the offset.
- On the 29 development figures of the bench's tree stratum: 29 captured (was 28); 92.3% of layer elements checked (was 40.1%), none failed (was 212); every layer element checked in 23 of 28 ggplot figures (was 15 of 27), none left without a single checked element (was 3). On v0's 54 development figures, no element that was checked before is unchecked now, and failed elements went from 8 to 6.

## Patchwork panels and base expected counts (2026-11-11, M1)

- A patchwork composition has the panels of each of its ggplots in `fig$substrate$panels`, named by the plot's place in the composition (`plot2_panel1`), with their scales, and its leaves lie in them. A plot whose build draws random numbers has its panels withheld with the reason, beside the other plots' panels; so do plots patchwork places as insets or gtables, which have no build. The page is drawn as before (patchwork's `print()`): on the 55 development figures every page equals the previous run's.
- More base leaves have an expected count, so a base leaf that draws more or fewer elements than its call asks for is caught: `polygon()`, `polypath()`, `arrows()`, `abline()`, `symbols()` (circles, squares, rectangles) and `plot()`/`lines()` of types `"b"`, `"o"`, `"h"`, `"s"`, `"S"`, `"c"` and `"n"`. On the 10 base development figures, leaves without a count fell from 574 to 57, the axes, boxes and titles, and none is a count mismatch.

## Fixes found by the first binding run (2026-11-11)

- `gloss()` no longer changes a recorded plot it is given. Capturing a recorded grid page wrapped the leaves of grid's display list in place, and that list is the one inside the recording, so a second `gloss()` of the same object stopped with "Capture integrity check failed: 0 probes drew". gloss now replays a deep copy. Captures are otherwise unchanged: on the 55 development figures every column of the capture run equals the previous run's, apart from the times.

## Page capture (2026-11-11, ADR-0006)

- `gloss()` lets the figure draw itself on its svglite device and captures that page: an object is printed (`show()` for S4), a grob drawn with `grid.draw()`, a function called, a recorded plot replayed. Engines no longer build the grob gloss draws. An object with its own `print()` method is captured as what that method draws (ggbreak's cut axis, ggExtra's marginal plots); the refusal by class is gone.
- gloss compares the captured page with the page drawn, primitive for primitive and with clip regions. Equal: captured. A figure that draws differently each time (random label placement, for example) is captured with a warning and the verdict `not_deterministic`. A capture that changed the figure stops with an error. The verdict, the kind of page, how it was drawn and the page count are in `meta$page` and printed with the figure.
- A function or a recorded plot that draws with grid is captured by the grid engine; it used to stop with "EXPR must be a length 1 vector". A grob whose name is a vector (treemap) is captured. A page with nothing on it and a page mixing base graphics and grid are refused with the reason. An input that draws several pages is captured as its last page, with a warning.
- Engine plugins: `grob(state)` is no longer part of the contract. New optional fields: `page` (`"grid"` or `"base"`), which chooses among engines declaring the same class, and `draw(state)`, for an engine that must keep what drawing returns (ComplexHeatmap's drawn list); its page must be the page the input draws, and `gl_test_plugin()` checks it on `example()`.
- A base-graphics page is captured as base graphics draws it on svglite, no longer as gridGraphics redraws it: its display list is replayed one entry at a time and each entry's primitives become one leaf, named by its call (`plotXY`, `text`, `axis`, `rect`, ...), with expected counts for points, lines, text, rectangles and segments. On 26 hand-built base pages the captured page equals the code's own page in 26 (through gridGraphics: 14; `pairs()`, `persp()`, `image()`, dendrograms, `rect(border = 0)` and `par(bg =)` differed, plotmath stopped with an error). Panels are the figures of the page with their plot region and `usr` scales. A plot recorded elsewhere is replayed with svglite's text metrics, noted in `meta$page$note`.
- `equal` means the captured page is the page gloss drew; it does not mean the figure draws the same page every time. A heatmap that runs k-means inside `draw()` is captured `equal`, while two drawings of it differ.
- gridGraphics is no longer used or suggested. On the 55 figures of the bench development set, 52 are captured equal to the page their code draws, 2 draw differently each time, 1 is refused with the reason, and none is captured as a different figure.
- On the 54 held-out figures of the bench (one run, predictions committed before it): 50 are captured equal to the page their code draws, 2 draw differently each time, 2 are refused, and none is captured as a different figure. The engine route at its last commit, on the same figures and by its own, more lenient comparison: 40 equal, 5 known exceptions, 8 different, 1 refused.
- A base page drawn after a grid page on the same device (the last figure of a script or vignette, for example) is captured as a base page. It was refused as a page mixing base graphics and grid, because the earlier page's grobs were still on grid's display list; the page kind is now read from the device's display list. This is what refused the two held-out figures above; it was fixed after that run, and the held-out numbers are the ones before the fix.
- A ggplot's built tables are the data drawn even when the build draws random numbers (`position_jitter()` without a seed): the engine draws the build it keeps, as ggplot2's `print()` does. They used to come from another build, which put none of 32 jittered rows on their point.
- Tables and panels that gloss cannot show describe the page drawn are withheld, with the reason in `fig$status$withheld` and in the printed figure: the built data and panels of a ggplot printed by another class's print method (ggbreak), the built data of a patchwork plot whose two builds differ, and panels whose number does not match the page. Raw tables are kept.

## Fixes found by the bench development set (2026-11-10)

- A ggplot without layers is captured, alone or as a wrapped patchwork element (`wrap_elements()`, `wrap_ggplot_grob()`); it used to fail with "subscript out of bounds".
- A ggplot extension whose own `ggplot_build()` returns something other than a built ggplot (gganimate's animations) is refused with the reason, instead of failing while drawing.
- A figure whose `print()` method is not a standard draw path (ggbreak's cut axis, ggExtra's marginal plots) is refused with the reason, instead of being captured as a different figure with no error. Correction (2026-11-10, later): only ggbreak's figure was captured as a different one. ggExtra's `print()` draws the same grob gloss captured; it is refused because the check is by class, which is stricter than needed.
- A clipping grob (`grid::clipGrob()`) keeps clipping the leaves drawn after it. It used to be wrapped in a graphics group like any leaf, which ended its clip with the group: the following leaves were captured unclipped, with no error. It is no longer listed as a leaf (it draws nothing).
- Bench capture runs (development only) now record a fidelity verdict per figure, the primitives that differ, known exceptions with their reason, and which leaves carry a count mismatch.

## M0: the substrate (2026-11-09)

- `gloss()` captures a ggplot, patchwork, ComplexHeatmap, base (through gridGraphics) or grid figure into a read-only substrate. Each leaf grob is drawn once inside its own graphics group with a zero-output probe, so every drawn element is attributed by the device to its leaf, viewport and panel. A leaf whose expected and drawn element counts differ is marked `count_mismatch` and is not bindable. Masked figures are refused.
- Geometry queries: `gl_elements()`, `gl_leaf()`, `gl_panels()`, `gl_hit()`, `gl_near()`, `gl_overlap()`, `gl_to_pixel()`, `gl_to_data()`.
- Tables (raw, built and engine-specific) with inferred row keys (`gl_infer_key()`, five rules in order, each recorded with its basis), `gl_tables()`, `gl_table()`, `gl_key_values()`, and `gl_key()` to change a key.
- Leaves with 10,000 or more elements are kept as a raster drawn from the same grob plus a binary geometry index.
- Context is sniffed at capture time (code, data, engine, environment, document, git) and listed by `gl_context()`; items that cannot be found carry a reason.
- `gl_write()` writes a bundle directory or a single HTML or SVG file with the bundle embedded; `gl_read()` restores either, as well as bundles without data, bundles naming a missing plugin, and plain SVG (geometry only). `embed =` chooses which data travel.
- Plugins: `gl_register()`, `gl_unregister()`, `gl_plugin()`, `gl_plugins()`, `gl_plugin_kinds()`, `gl_test_plugin()`, `gl_schema_check()`, `gl_schema_validate()`. The built-in engines, context sniffers and projections register through `gl_register()`.
