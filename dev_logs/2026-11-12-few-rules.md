## Surprises

- **The principle pushed toward rules, not only the metric.** "What code can determine is never left to a model" has no stopping point: ggimage's justification and shadowtext's halo can be determined by code, so they were. The design's own binding stage (an agent proposes, code checks) was never reconciled with it. → ADR-0009.
- **Most of the residue is not what a proposal about a package can reach.** 2070 of 5232 elements are a package's behaviour, and 1829 of those are one class that has no comparison at all. The owner's "an agent repairs incomplete bindings" may move few elements on these sets; by figures it is 11 of 83. → idea note, *Where it starts*; ADR-0009, negative consequences.
- **With no free numbers a leaf's proposals are a finite list, so code can try them all.** The design assumed a model proposes a binding. An enumeration may do as well; whether it does is not measured. → idea note, the research card's rival and the experiment's arm S.
- **The three rules outside the line all concern packages the owner's lab maintains** (ggtree, ggimage, shadowtext). A plugin for a package, or the package stating how it draws, is a real alternative for them. → ADR-0009, *Alternatives* and *Revisit when*.
- **A tarball built from this working tree packed `.claude/`, `.rho/` and `.workbuddy/`, and I reported it wrongly twice.** I read the check log and the tarball of an older temporary directory (a build of 2026-11-11, found by a glob), told the owner the two NOTEs were the version number and the clock, and then took back a true observation (the build's warnings about `.rho` paths) as false. `.claude/settings.local.json` holds three permission lines and no credential, and the tarball never left the machine. `.Rbuildignore` listed none of the three. A build's output is now read from the directory the build was started in, by its path. → `.Rbuildignore`; this log. Whether the two untracked tool directories also belong in `.gitignore` is the owner's call: nowhere yet.
- **Three records lag the code.** The callout at the top of `design.qmd` still says M1 "还没有代码"; `README.md`'s status does not mention binding; neither was touched, since the owner asked for three records. → What's next.
