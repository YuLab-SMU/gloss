## What changed

- Added `count`, `value`, `compare`, `range` and `exists` check plugins with evidence-bearing statuses beside `trend`.
- Added explicit JSON-like schemas and projection eligibility for semantic records, including speculative status and executable-payload rejection.
- Added the operation registry and `gl_apply()` for 11 R-side operations. Anchors resolve through the existing conservative selector path. SVG overlays are generated separately from the captured scene.
- Added a dependency-free HTML runtime with four browser operations and operation state persistence in bundles.
- Added `gl_export()` for ARIA, plain text and Web Annotation JSON projections.
- Added the deterministic M3 fixture and archives under `bench/runs/2026-11-16-m3*`.

## Surprises

- The first full-suite run found an internal name collision between the new semantic grouping helper and the binding module's existing helper. Renaming the semantic helper restored the previous binding behavior. → fixed in `0a2de91`, covered by `test-bind.R`.
- The package's schema normalizer used partial `$type` matching and treated an optional `type?` field as the schema's type. Exact indexing fixed the issue and keeps optional schema fields valid. → fixed in `ae730ff`, covered by record and schema tests.
