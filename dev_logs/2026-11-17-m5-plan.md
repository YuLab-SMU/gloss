## What changed

Opened M5 from the measured M4 state. The plan starts with a development-only semantic task bank, information-parity materials, a cost gate and deterministic scoring contracts. The held-out A/B and 2×2 comparison is deferred until the development pilot fixes the eligible figure subset, model ids, prompt versions, loop, retry policy and budget.

Registered M5 predictions 151–160 and an operational budget in [`bench/predictions.md`](../bench/predictions.md). The predictions cover material leakage, deterministic claim checking, the structure/check ablation, perturbation and counterfactual behavior, masked-versus-audit ordering and the multi-selector anchor path.

Updated [`plan/README.md`](../plan/README.md) so the active slice points to the M5 plan. No package code, held-out semantic material or model run was changed.

## Measured

- `NOT_CRAN=true Rscript -e "devtools::test()"` → 22 files, 1644 passed, 0 failures and 0 skips; duration 281.7 seconds.
- M4 development preflight → 54/55 v0 figures and 29/29 tree figures captured. Every captured figure passed scene-unchanged, operation round-trip, ARIA parse, annotation parse and embedded-runtime checks. Chromium and Playwright were unavailable, and Node was available for static runtime checks.
- M4 scripted semantic path → one checked claim committed, substrate unchanged and bundle round trip retained under `bench/runs/2026-11-17-m4-pilot/`.
- M4 real smoke → one checked `meaning` record, three rejected proposals, 5,594 tokens and one gateway retry on fixed mtcars. The interrupted claim traces used 373,889 tokens over 144.8 seconds and 34,081 tokens over 69.4 seconds without a candidate.
- No M5 semantic, perturbation, counterfactual, 2×2, masked-audit or update-ablation run was made on held-out figures.

## Surprises

- The real claim-stage cost varies by an order of magnitude between runs, with a 373,889-token trace that produced no candidate. This makes the cost gate the first M5 task and keeps the full semantic matrix out of the opening scope. → plan Task 1 and the registered operational budget.
- The held-out set is not globally untouched because capture and tree binding were already run under their earlier registered plans. Semantic layers and the new M5 transformations remain untouched. → plan starting state and Task 4 boundary.
- Chromium and Playwright are still unavailable. M5 therefore keeps browser automation optional and relies on static runtime checks unless the environment changes. → plan architecture and out-of-scope list.
