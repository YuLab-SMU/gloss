## What changed

M4 now has a stage-scoped agent path over the existing substrate. The package registers ten stages with versioned prompts, constructs tools from declared layer and disclosure capabilities, validates semantic proposals before deferred append, and records stage provenance. `gl_annotate()` runs dependency-ordered stages with explicit limits and cache replay. Review and repair remain scoped to the original conflict, layer and anchor. The development preflight and pilot scripts archive their evidence under `bench/runs/`.

The current design, plan index and `NEWS.md` describe the delivered behavior. The M4 plan is closed and moved to `plan/done/`.

## Surprises

- The M3 operation round-trip exposed an empty `focus` vector returning with the wrong R type. `R/operations.R` and `R/core-bundle.R` now normalize the storage form, with a regression test. → plan Task 1 result and the current implementation.
- The first real claim-stage traces spent 373,889 tokens over 144.8 seconds without a candidate, then 34,081 tokens over 69.4 seconds and still stopped before `propose`. The claim tool set and prompt were narrowed and made explicit. → plan scope changes.
- The gateway cost made the original six-figure matrix unsuitable as an M4 completion gate. A checked two-step smoke is the measured real-model signal, while the larger comparison is deferred. → plan scope change and `dev_docs/design.qmd` risk note.
- The pinned bench image lacks aisdk, so five agent tests are explicit environment skips there while the host suite covers the available aisdk path. → plan Task 7 verification and the next M5 environment setup.
